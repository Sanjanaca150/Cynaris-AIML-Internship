# W5D3: ChromaDB – Vector Store Setup & Embedding Documents

## 📌 Objective

This project demonstrates the implementation of a Vector Store using **ChromaDB** and semantic retrieval using **Sentence Transformers**. It also integrates **Ollama** to answer questions based on the retrieved document context.

---

## 🚀 Technologies Used

- Python
- Google Colab
- ChromaDB
- Sentence Transformers
- PyPDF
- Ollama (Llama 3.2:3b)

---

## 📋 Tasks Completed

- Installed ChromaDB
- Created a ChromaDB collection
- Added 20 documents with embeddings
- Performed cosine similarity search
- Applied metadata filtering
- Verified retrieval results manually
- Embedded a PDF document
- Split the PDF into chunks
- Generated embeddings for PDF chunks
- Stored PDF chunks in ChromaDB
- Retrieved the top 3 relevant chunks
- Passed the retrieved chunks to Ollama
- Generated and verified the final answer

---

## 📂 Project Files

- `W5D3_ChromaDB_Vector_Store.ipynb` – Main notebook containing the implementation.
- `ollama_rag.py` – Python script for querying the local Ollama model using the retrieved context.

---

## 📖 Workflow

1. Install required libraries.
2. Create a ChromaDB collection.
3. Add documents with embeddings.
4. Perform similarity search.
5. Apply metadata filtering.
6. Read and process a PDF.
7. Split the PDF into chunks.
8. Generate embeddings for PDF chunks.
9. Store chunks in ChromaDB.
10. Retrieve the top 3 relevant chunks.
11. Pass the retrieved chunks to Ollama.
12. Generate the final answer.

---

## 🎯 Learning Outcomes

- Understood vector databases and embeddings.
- Learned semantic search using cosine similarity.
- Implemented document retrieval with ChromaDB.
- Integrated a local LLM (Ollama) for Retrieval-Augmented Generation (RAG).
- Built an end-to-end semantic document retrieval pipeline.
