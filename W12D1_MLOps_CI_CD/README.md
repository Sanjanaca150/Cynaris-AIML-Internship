\# W12D1 MLOps CI/CD



\## Overview



This project demonstrates an MLOps workflow for a containerized machine learning API.



\## Features



\- FastAPI ML API

\- Health monitoring endpoint

\- Prediction endpoint

\- Automated tests

\- Docker containerization

\- GitHub Actions CI/CD

\- Ruff linting

\- Docker image building

\- Docker registry push

\- Monitoring strategy documentation



\## Technology Stack



\- Python 3.12

\- FastAPI

\- Uvicorn

\- NumPy

\- Scikit-learn

\- Joblib

\- Pytest

\- Ruff

\- Docker

\- GitHub Actions

\- MLflow for future experiment and model tracking
