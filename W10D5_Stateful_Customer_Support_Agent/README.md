\# W10D5 - Stateful Customer Support Agent



\## Objective



A stateful customer support agent built using LangGraph, CrewAI, Ollama and MLflow.



\## Features



\- Stateful customer conversations using LangGraph

\- Persistent conversation memory using thread IDs

\- Local LLM using Ollama

\- Customer issue analysis

\- Human escalation for sensitive requests such as refunds

\- CrewAI support analysis

\- MLflow experiment tracking

\- Automated tests

\- Evaluation of state retention and escalation detection



\## Technologies



\- Python 3.12

\- LangGraph

\- CrewAI

\- LangChain

\- Ollama

\- MLflow

\- Ragas
